🌌 Proyecto Orion

Sistema de Detección de Hurto de Energía

De los Datos a la Acción con Closed Loop

📋 Propósito

El Proyecto Orion es un sistema de código abierto diseñado para ayudar a las empresas distribuidoras de energía eléctrica a detectar y priorizar posibles casos de hurto de energía (pérdidas no técnicas). Utiliza modelos de Machine Learning para analizar patrones de consumo y priorizar inspecciones en campo.

🎯 Objetivos

  • Detectar suministros con alta probabilidad de hurto (Precisión > 85%)
  • Priorizar inspecciones por impacto económico (Top 100 > 95% acierto)
  • Recuperar energía no registrada (CNR > 80% del estimado)
  • Prevenir reincidencia (Reducción > 30%)

🔧 ¿Qué hace la aplicación?

La aplicación se conecta a tu cuenta de Google Drive para almacenar los resultados del análisis de forma segura. No accede a ningún otro dato de tu cuenta.

Los permisos solicitados son:

  • Crear, leer y modificar archivos que la aplicación misma ha creado
  • Almacenar resultados de análisis en una carpeta específica
  • Recuperar datos históricos para el dashboard
