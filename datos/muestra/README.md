# Datos de Muestra - Proyecto Orion

Esta carpeta contiene datos sintéticos para pruebas y desarrollo.

## Archivos

| Archivo | Descripción | Registros |
|---------|-------------|-----------|
| `clientes_muestra.csv` | Información de clientes | 50 |
| `consumo_muestra.csv` | Consumo diario (365 días) | 18,250 |
| `alarmas_muestra.csv` | Eventos de alarmas | ~182 |
| `facturacion_muestra.csv` | Facturación | ~400 |
| `inspecciones_muestra.csv` | Historial de inspecciones | ~75 |

## Generación

Los datos se generan con `scripts/generar_datos_muestra.py`
